# Content JSON schema

Each matn is one read-only JSON file in `Resources/Content/`, generated by
`Tools/build_matn.py` from a hand-verified `Tools/sources/<id>.txt`. The app
decodes it into the `Matn` type in `Core/Models/Matn.swift`.

This content is **text and layout only**. A user's progress, marks, and slip
history live separately in SwiftData and reference bayts by `(matnID,
baytNumber)`. The two are never mixed: re-building a matn's JSON must never
touch a user's marks.

## Top level

| field          | type        | meaning                                             |
|----------------|-------------|-----------------------------------------------------|
| `schemaVersion`| int         | bump when the shape changes (currently `1`)         |
| `id`           | string      | stable id, e.g. `"tuhfa"`                           |
| `title`        | string      | Arabic title                                        |
| `titleLatin`   | string      | transliteration, e.g. `"Tuhfat al-Atfal"`          |
| `author`       | string      | Arabic author name                                  |
| `meter`        | string      | the baḥr, e.g. `"الرجز"`                            |
| `baytsPerPage` | int         | layout rule — `10` for this project                 |
| `pageCount`    | int         | derived: `ceil(baytCount / baytsPerPage)`           |
| `baytCount`    | int         | total number of bayts                               |
| `babs`         | `[Bab]`     | chapter headings, in order                          |
| `bayts`        | `[Bayt]`    | every bayt, in order                                |

## Bab

| field        | type   | meaning                                  |
|--------------|--------|------------------------------------------|
| `id`         | string | stable id, e.g. `"nun-sakinah"`          |
| `title`      | string | Arabic heading                           |
| `startBayt`  | int    | first bayt number in this bab            |
| `endBayt`    | int    | last bayt number (inclusive)             |

Babs are contiguous and cover every bayt exactly once (checked by the validator).

## Bayt

| field        | type     | meaning                                              |
|--------------|----------|------------------------------------------------------|
| `number`     | int      | 1-based, continuous within the matn                  |
| `page`       | int      | 1-based page in the 10-per-page layout               |
| `row`        | int      | 1-based position on the page (1..baytsPerPage)        |
| `babId`      | string   | the `Bab.id` this bayt belongs to                    |
| `sadr`       | string   | first hemistich (shown on the **right**)             |
| `ajuz`       | string   | second hemistich (shown on the **left**)             |
| `sadrWords`  | `[Word]` | the sadr split into words                            |
| `ajuzWords`  | `[Word]` | the ajuz split into words                            |

## Word

| field  | type    | meaning                                                      |
|--------|---------|--------------------------------------------------------------|
| `text` | string  | the vowelled word exactly as displayed                       |
| `norm` | string  | match-only normalized form (see below) — never displayed     |
| `red`  | bool?   | present and `true` when the word is printed in red in the PDF |

Every word is modelled individually so the Reader can show, hide, underline,
circle, colour, or reveal any single word without the page reflowing.

### Red words

Rule names (الإظهار, الإدغام…) and the mnemonic "codes" (يَرْمَلُون, كم عسل نقص,
the rasm example words…) are printed in red in the matn. In the source `.txt`
they are wrapped in `*asterisks*`; `build_matn.py` strips the asterisks and sets
`red: true` on each word inside. Words without the flag are ordinary (the flag is
omitted, not set to `false`, to keep the JSON small). The app decodes a missing
flag as not-red.

### Normalization (`norm`)

Applied by `Tools/normalize.py`; the app must apply the identical rules at
runtime so voice-test matching lines up with what we stored:

- strip all harakat (tashkeel) and other combining marks
- strip tatweel (ـ)
- `أ إ آ ٱ` → `ا`
- `ى` → `ي`
- `ة` → `ه`
- drop anything that isn't an Arabic letter (punctuation, parentheses, digits)

Example: `رَحْمَةِ` → `رحمه`, `(تُحْفَةِ` → `تحفه`, `عَلَى` → `علي`.
